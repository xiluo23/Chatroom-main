# 集群通信服务系统（Distributed Chatroom System）

## 项目简介

本项目是一个基于 C++ 开发的高并发集群通信系统，旨在实现支持多节点部署的即时通讯服务。系统采用 **Epoll（ET）+ Reactor** 网络模型构建高性能服务端，结合 **Node.js WebSocket 接入层、Nginx TCP 负载均衡、Redis Pub/Sub 跨节点消息同步以及 MySQL 数据持久化存储**，实现了一个具备高并发处理能力、分布式扩展能力以及在线部署能力的聊天室系统。

---

## 核心特性

* 基于 **Epoll（ET）+ Reactor** 的高并发网络模型
* 支持 **TCP 长连接** 与 **WebSocket 实时通信**
* 支持 **集群部署与多节点扩展**
* 支持 **单播、广播、多播、离线消息**
* 基于 **Redis Pub/Sub** 实现跨节点消息同步
* 基于 **Nginx TCP Load Balance** 实现流量分发
* 基于 **线程池 + 连接池** 提升吞吐能力
* 基于 **环形缓冲区** 处理粘包拆包问题

## 系统架构

系统整体采用分层架构设计：

### 1. 客户端层

浏览器作为客户端，通过 WebSocket 与服务端建立长连接，实现实时消息收发。

### 2. 接入层

Nginx 作为统一入口，负责：

* TCP 请求转发
* 负载均衡
* 流量分发

Node.js 负责：

* WebSocket 握手
* 前端协议适配
* 消息转发

### 3. 业务处理层

核心服务由 C++ 实现，负责：

* 网络事件监听
* 协议解析
* 消息处理
* 用户状态维护
* 消息路由

采用 **Reactor 模型** 将处理流程划分为：

事件监听 → 协议解析 → 业务处理 → 响应回写

### 4. 数据存储层

#### MySQL

负责：

* 用户信息存储
* 聊天记录持久化
* 离线消息存储

#### Redis

负责：

* 在线状态缓存
* 节点间消息同步
* Pub/Sub 发布订阅

## 核心设计

### 1. Epoll + Reactor 高并发模型

系统采用 **非阻塞 Socket + Epoll ET 模式**。

主线程负责：

* accept 新连接
* 监听可读可写事件
* 分发任务

工作线程负责：

* 业务逻辑执行
* 数据库访问
* Redis 通信

优势：

* 减少线程切换
* 降低系统调用开销
* 提高高并发处理能力

---

### 2. 自定义应用层协议

为解决 TCP 粘包拆包问题，系统设计了：

**长度前缀 + 消息体** 协议格式：

| 字段             | 长度       |
| -------------- | -------- |
| message_length | 4 Bytes  |
| message_body   | Variable |

其中消息头使用网络字节序存储消息长度，用于准确解析 TCP 字节流中的消息边界。

---

### 3. 环形缓冲区

每个连接维护独立环形缓冲区：

* head：读指针
* tail：写指针

作用：

* 缓存未解析完整的数据
* 支持 ET 模式下持续读取
* 减少内存重复申请与释放

优势：

* 降低拷贝开销
* 提高吞吐性能
* 优化高并发内存管理

---

### 4. 动态线程池

系统实现任务队列驱动的线程池：

任务包括：

* 用户登录验证
* 消息广播
* 状态维护
* 数据库访问

作用：

* I/O 与业务解耦
* 降低主线程阻塞
* 提高资源利用率

---

### 5. 集群通信机制

系统支持多节点部署：

当用户 A 与用户 B 位于不同服务器节点时：

1. 当前节点封装消息
2. 调用 Redis Publish
3. Redis 推送到目标频道
4. 目标节点 Subscribe 收到消息
5. 转发给目标客户端

实现跨节点消息通信。

## 性能测试

测试环境：

* Ubuntu 22.04
* 2 Core CPU
* 4GB RAM
* 100 Mbps Bandwidth

测试结果：

| 并发连接数 |     QPS |    平均响应时间 |
| ----- | ------: | --------: |
| 50    | 5452.48 |   8.43 ms |
| 500   |   5900+ |   <100 ms |
| 1000  | 6291.43 | 154.23 ms |

结果表明：

* 1000 并发连接成功率保持 100%
* 系统吞吐量稳定在 5452~6291 QPS
* Reactor 模型具备良好的中高并发处理能力
